# ⚡ Byte Size - URL Shortener

> Transform those monstrously long URLs into sleek, shareable links in seconds! 🚀

![Version](https://img.shields.io/badge/version-1.0.0-blue.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)

Ever tried sharing a URL that looks like a phone number from the 90s? Yeah, we've been there too. **Byte Size** is here to rescue your messages, tweets, and documents from URL overload! 

## ✨ Features

- **🎯 One-Click Shortening** - Paste, click, done! No complicated setup required
- **📋 Copy to Clipboard** - Instantly copy your shortened URL with a single click
- **🎨 Modern UI** - Beautiful gradient design with smooth animations
- **📱 Fully Responsive** - Works perfectly on desktop, tablet, and mobile
- **⚡ Real-time API** - Powered by Rebrandly's lightning-fast URL shortening service

## 🚀 How It Works

1. **Paste** your long URL into the input field
2. **Click** the "Shorten" button
3. **Voilà!** Your shortened URL appears instantly
4. **Copy** it with one click and share it anywhere!

## 🛠️ Tech Stack

- **HTML5** - Semantic markup for accessibility
- **CSS3** - Modern styling with CSS variables, flexbox, and gradients
- **JavaScript** - No frameworks, just pure JS magic
- **Rebrandly API** - Professional URL shortening service

## 📦 Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/madildev/Url-Shortner.git
   cd Url-Shortner
   ```

2. **Set up your API key**
   - Sign up at [Rebrandly](https://www.rebrandly.com/) to get your free API key


## 🎨 Customization

Want to make it your own? Here's what you can customize:

- **Colors**: Edit CSS variables in `public/style.css`
- **Social Links**: Update URLs in `index.html` footer
- **API Provider**: Swap Rebrandly for another service in `public/main.js`
